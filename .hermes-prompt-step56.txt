### What To Build

Create/modify the following:

#### 1. Server: Add `changed_by_name` filter to `GET /api/audit-log`
In `server/index.cjs`, around line 2077-2088, add a `changed_by_name` filter parameter. When provided, use `ILIRE` for partial matching:
```javascript
if (changed_by_name) {
  conditions.push(`changed_by_name ILIKE $${idx++}`);
  params.push(`%${changed_by_name}%`);
}
```

#### 2. Server: Add `GET /api/audit-log/tables` endpoint
In `server/index.cjs`, add an endpoint that returns distinct table names from the audit log:
```javascript
app.get("/api/audit-log/tables", async (req, res) => {
  try {
    const { rows } = await pool.query(
      `SELECT DISTINCT table_name FROM shared.audit_log ORDER BY table_name`
    );
    res.json(rows.map(r => r.table_name));
  } catch (err) {
    res.status(500).json({ error: err.message });
  }
});
```
Place this BEFORE the `GET /api/audit-log/:id` route (which catches `/tables` as an `:id` param) - put it at line ~2031 (before the existing audit-log group).

#### 3. Client: Add `getAuditTables()` to `src/lib/api.ts`

export function getAuditTables(): Promise<string[]> {

#### 4. Create `src/components/AuditLogPage.tsx`
A full-page component that shows the audit log with filters and a data table:

**State:**
- `entries: AuditEntry[]` — current page of results
- `total, page, pages, limit` — pagination state
- `loading: boolean`
- `error: string | null`
- Filter state: `tableName`, `action`, `changedByName`, `from`, `to`
- `availableTables: string[]` — fetched from `/api/audit-log/tables`

**Filter bar (top):**
- Responsive flex layout with filter controls
- **Table filter**: `<select>` dropdown populated from `availableTables`, with "All Tables" default option
- **Action filter**: `<select>` with options: "All", "INSERT", "UPDATE", "DELETE"
- **User filter**: `<input>` text field with placeholder "Filter by user name..." — free-text search
- **Date range**: Two `<input type="date">` fields for From and To
- **Search button**: Triggers a new fetch with current filter values
- **Clear button**: Resets all filters

**Data table:**
- Renders as a styled HTML table inside a scrollable container
- Columns: Timestamp | User | Table | Action | Changes
- Timestamp: formatted as "YYYY-MM-DD HH:mm" (full format, not relative — this is the full log page)
- User: `changed_by_name` or "—" if null
- Table: `table_name`
- Action: colored badge (green=INSERT, amber=UPDATE, red=DELETE)
- Changes: For UPDATE, show a summary of changed fields. For INSERT, show "New record created". For DELETE, show "Record deleted".
- Each row is clickable (can expand/collapse to show old/new values in a detail row below)

**Empty state:** Centered message "No audit log entries found" when 0 results

**Error state:** Red error banner with retry button

**Loading state:** Spinner/skeleton

**Pagination footer:**
- Shows "Page X of Y (Z total)"
- Previous/Next buttons
- Page size selector: 20, 50, 100

**Export button:** In the top-right of the page header, "[Export CSV]" button that:
- Fetches all matching results (no pagination)
- Formats as CSV with columns: Timestamp, User, Table, Action, Field, Old Value, New Value
- Triggers a download via `URL.createObjectURL(new Blob([csv], { type: 'text/csv' }))`

**Styling:**
- Use the same Tailwind patterns as the rest of the app (small fonts, minimal borders)
- Use shadcn components where applicable (Button, Select, Input from `@/components/ui/`)
- Keep consistent with TableBrowser's styling for the data table
- The page should fill the main content area (flex-1, h-full)
