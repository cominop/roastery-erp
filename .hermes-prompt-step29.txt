Implement Step 29: Quick filter buttons (preset shortcuts above data table)

## Context
This is the Roastery ERP, a form-based ERP UI built with React 19, TypeScript, Vite, and Tailwind CSS 4. The filtering infrastructure is now fully built:
- Step 24: `useFilters` hook at `src/hooks/useFilters.ts` — manages filter state (add/remove/toggle/clear filters, combined SQL WHERE clause)
- Step 25: `FilterPanel` component at `src/filters/FilterPanel.tsx` — collapsible filter management UI
- Step 26: Type-specific filter controls at `src/filters/FilterControlFactory.tsx` (text ILIKE, number range, date range, boolean, lookup)
- Step 27: Server-side filter → SQL translation at `server/filters-to-where.cjs`
- Step 28: URL persistence at `src/hooks/useFilterUrlSync.ts` — encode/decode filter state in query params

## Task
Create a **QuickFilterBar** component: a row of preset shortcut buttons that sit above the data table (above the FilterPanel). Each button applies a pre-configured filter instantly with one click. These are convenience shortcuts for common filtering patterns.

### Requirements

1. **Create `src/filters/QuickFilterBar.tsx`** — a horizontal bar of preset filter buttons:

   ```tsx
   interface QuickFilterPreset {
     /** Unique identifier for this preset */
     id: string;
     /** Display label shown on the button */
     label: string;
     /** The filter to apply when clicked — expression + name */
     filter: { name: string; expression: string };
     /** Optional: icon name or description */
     icon?: string;
   }

   interface QuickFilterBarProps {
     /** Available preset shortcuts */
     presets: QuickFilterPreset[];
     /** Called when a preset is clicked. Receives the preset's filter. */
     onApplyPreset: (name: string, expression: string) => void;
     /** Currently active preset ids (highlighted buttons) */
     activePresets?: string[];
     /** Called when a preset is toggled off (clicked again while active) */
     onRemovePreset?: (id: string) => void;
   }
   ```

2. **Visual design:**
   - Renders as a horizontal scrollable row of small pill/chip buttons
   - Each button shows the label, optionally with a small icon
   - Active (applied) presets are visually distinct — filled/accent background vs outline for inactive
   - Buttons are compact: `h-7` height, `text-xs`, `px-2.5` padding
   - The bar has a subtle bottom border to separate from the content below
   - Use `flex gap-1.5` with `overflow-x-auto` for horizontal scrolling on narrow screens
   - Use Tailwind classes only — no CSS modules or external stylesheets
   - Use the `cn()` utility from `@/lib/utils` for conditional class merging

3. **Behavior:**
   - Clicking a preset button calls `onApplyPreset(name, expression)` which invokes `addFilter()` from `useFilters`
   - Clicking an already-active preset toggles it off — calls `onRemovePreset(id)` which should lead to `removeFilter()`
   - A preset is "active" when its `id` appears in `activePresets` array
   - Multiple presets can be active simultaneously (each adds a separate filter)
   - Presets can coexist with filters added via the FilterPanel — the same `useFilters` hook manages everything

4. **Export from `src/filters/index.ts`** — add `QuickFilterBar` to the barrel export

5. **Integration pattern:**
   The QuickFilterBar is designed to be used by any page/view that renders a data table. The integration pattern is:
   ```tsx
   const { filters, addFilter, removeFilter, ...rest } = useFilters();
   
   // Determine which presets are active
   const activePresetIds = filters
     .filter(f => f.name.startsWith("preset_"))
     .map(f => f.name.replace("preset_", ""));
   
   const handleApplyPreset = (name: string, expression: string) => {
     addFilter(name, expression);
   };
   
   const handleRemovePreset = (id: string) => {
     // Find the filter with name starting with "preset_"+id
     const filter = filters.find(f => f.name === `preset_${id}`);
     if (filter) removeFilter(filter.id);
   };
   
   // Render
   <QuickFilterBar
     presets={PRESETS}
     activePresets={activePresetIds}
     onApplyPreset={handleApplyPreset}
     onRemovePreset={handleRemovePreset}
   />
   <FilterPanel
     filters={filters}
     activeFilters={rest.activeFilters}
     ...
   />
   ```
