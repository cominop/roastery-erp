## Files to Create

### 1. `src/filters/FilterControls.tsx` — Filter type dispatcher
A component that receives the field definition and renders the appropriate filter control:
```tsx
interface FilterControlProps {
  fieldName: string;
  fieldType: 'TEXT' | 'INTEGER' | 'FLOAT' | 'CURRENCY' | 'DATE' | 'DATETIME' | 'BOOLEAN' | 'LONGTEXT' | 'LOOKUP' | 'FILE' | 'IMAGE';
  caption: string;
  value: any;
  onChange: (value: any) => void;
  operator?: string;
  onOperatorChange?: (operator: string) => void;
}
```

Route by fieldType:
- TEXT, LONGTEXT → TextFilter
- INTEGER, FLOAT, CURRENCY → NumberFilter
- DATE, DATETIME → DateFilter
- BOOLEAN → BooleanFilter
- LOOKUP → LookupFilter
- FILE, IMAGE → BooleanFilter (Has file? Yes/No)

### 2. `src/filters/TextFilter.tsx` — Text ILIKE search
- Text input with an operator dropdown (Contains / Equals / Starts with / Ends with)
- Debounced onChange (300ms)
- Placeholder text: "Search {caption}..."
- data-testid: "text-filter-{fieldName}"

### 3. `src/filters/NumberFilter.tsx` — Number range filter
- Number input with operator dropdown (Greater than / Less than / Equals / Range / Between)
- When operator is "range" or "between", show two inputs (min/max)
- Validation: only numeric input
- Placeholder: "Min" / "Max" for range mode
- data-testid: "number-filter-{fieldName}"

### 4. `src/filters/DateFilter.tsx` — Date range filter
- Two date inputs for from/to range selection
- HTML date inputs (type="date" for DATE, type="datetime-local" for DATETIME)
- Default: show from/to
- Clearable individual dates
- data-testid: "date-filter-{fieldName}"

### 5. `src/filters/BooleanFilter.tsx` — Boolean dropdown
- Three-option select: "All" / "True" / "False"
- "All" means no filter applied (null value)
- data-testid: "boolean-filter-{fieldName}"

### 6. `src/filters/LookupFilter.tsx` — Lookup dropdown with search
- Select dropdown populated from a `lookupSource` table
- Search-as-you-type filtering of options
- Clearable selection
- Props include `lookupSource?: string` and `lookupField?: string`
- data-testid: "lookup-filter-{fieldName}"
