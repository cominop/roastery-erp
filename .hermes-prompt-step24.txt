## What to Build

Create the core filter state management hook at `src/filters/hooks/useFilters.ts`.

### Requirements

1. **Types** — Create `src/filters/schema/filterSchema.ts` with:
   - `FilterOperator` type: equals, not_equals, contains, starts_with, ends_with, greater_than, less_than, greater_equal, less_equal, range, in_list, not_in_list, is_null, is_not_null, custom
   - `FilterDefinition` interface: id, fieldName, fieldType (FieldType from existing types), caption, filterType (FilterOperator), defaultValue?, required, multiple, visible, collapsed, placeholder?, lookupSource?, lookupField?, rangeMin?, rangeMax?
   - `FilterState` interface: id, value (any), active (boolean), operator? (FilterOperator override)
   - `ViewFormFilterState` interface: filters (FilterState[]), filterLogic ('AND' | 'OR'), savedPresets (SavedFilterPreset[])
   - `SavedFilterPreset` interface: id, name, filters (FilterState[]), shared (boolean), userId?

2. **useFilters hook** — Create `src/filters/hooks/useFilters.ts` with:
   - `addFilter(definition: FilterDefinition)` — adds a new filter with default state to the list
   - `removeFilter(id: string)` — removes a filter from the list
   - `toggleFilter(id: string)` — toggles the active/inactive state
   - `setFilterValue(id: string, value: any)` — sets the current value of a filter
   - `setFilterOperator(id: string, operator: FilterOperator)` — overrides the operator
   - `clearAllFilters()` — removes all filters
   - `getActiveFilters()` — returns only active (enabled) filters with non-null values
   - `hasActiveFilters()` — returns boolean
   - `activeCount()` — returns count of active filters
   - `resetFilter(id: string)` — resets a filter to its default value
   - State is managed via useState (useReducer preferred for complex state)
   - Initial state should accept an array of FilterDefinition to pre-populate

3. **Export** — Create `src/filters/index.ts` that re-exports everything from schema and hooks

4. **Tests** — Create `src/filters/__tests__/useFilters.test.ts` with Playwright/React Testing Library tests:
   - Test adding a filter
   - Test removing a filter
   - Test toggling active state
   - Test setting value
   - Test clearing all filters
   - Test getActiveFilters filtering
   - Test activeCount
   - Test resetFilter
   - Test initial state with pre-populated definitions

5. **Integration** — Make sure the hook can be imported and used in a React component. Verify the types are compatible with existing FieldType from `src/types/` or wherever FieldType is defined.
