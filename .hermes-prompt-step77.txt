## What to Build

### 1. Template Registry (`src/visual-editor/templateRegistry.ts`)

Export the following:

**Types:**
```typescript
export interface FormTemplate {
  name: string;
  description: string;
  template: 'default' | 'tabs' | 'grid' | 'master-detail' | 'catalog';
  layout: {
    columns: 1 | 2 | 3 | 4;
    labelSize: 'xsmall' | 'small' | 'medium' | 'large' | 'xlarge';
    inPanel: boolean;
    tabs?: FormTemplateTab[];
  };
  options: {
    width: number;
    formBorder: boolean;
    formHeader: boolean;
    showHistory: boolean;
    closeButton: boolean;
    closeOnEscape: boolean;
    modeless: boolean;
    buttonsOnTop: boolean;
    multiSelect?: boolean;
    dblclickEdit?: boolean;
  };
}

interface FormTemplateTab {
  caption: string;
  bands: FormTemplateBand[];
}

interface FormTemplateBand {
  fields: string[];  // field names
}
```

**Five built-in templates:**
| Template | Layout | Description |
|----------|--------|-------------|
| `default` | Single column, label/input pairs, footer buttons | Simple editing |
| `tabs` | Nav-tabs header, each tab has bands of fields | Multi-section forms |
| `grid` | 2-3 column Bootstrap grid | Wide data-dense forms |
| `master-detail` | Split view: master table top, subform bottom | Orders + Line Items |
| `catalog` | Search bar + data table + action buttons | Browse/lookup only |

Each built-in template should be a full FormTemplate object with sensible defaults.

**Functions:**
- `getTemplates(): FormTemplate[]` — returns all registered templates (built-in + user)
- `getTemplate(name: string): FormTemplate | undefined` — get by name
- `registerTemplate(template: FormTemplate): void` — add a user template
- `unregisterTemplate(name: string): boolean` — remove a user template (can't remove built-ins)
- `saveUserTemplates(): void` — persist user templates to localStorage
- `loadUserTemplates(): FormTemplate[]` — load from localStorage
- `applyTemplateToForm(form: VisualEditorForm, template: FormTemplate, availableFields: FieldDefinition[]): VisualEditorForm` — applies a template to create a form definition:
  - For 'default': creates a single band with all available fields, 1 column
  - For 'tabs': creates tabs from template definition, each tab gets a band with the specified fields
  - For 'grid': sets column count from template, creates bands for field grouping
  - For 'master-detail': creates a detail section configuration for subform
  - For 'catalog': creates a view-form style layout with search/data-table/actions
  - Copies template options to the form

Import `VisualEditorForm` from `./types`.

### 2. Template Library Component (`src/visual-editor/TemplateLibrary.tsx`)

A panel that lets the user browse, preview, and apply templates.

**Props:**
```typescript
interface TemplateLibraryProps {
  form: VisualEditorForm;
  availableFields: FieldDefinition[];
  onApplyTemplate: (form: VisualEditorForm) => void;
  onClose: () => void;
}
```

Import `FieldDefinition` from the spec, or define a minimal local type:
```typescript
interface FieldDefinition {
  id: string;
  caption: string;
  name: string;
  type: string;
}
```

**UI:**
- A modal overlay with a grid of template cards (like a template chooser in PowerPoint/Canva)
- Each card shows:
  - Template name (bold)
  - Template type badge (e.g., "Tabs", "Grid")
  - Short description
  - Preview icon or visual indicator of layout
- Clicking a card:
  - Highlights it as selected
  - Shows a preview panel on the right with the template details
  - "Apply Template" button becomes active
- "Apply Template":
  - Calls `applyTemplateToForm()` with the current form + template + available fields
  - Calls `onApplyTemplate()` with the result
- "Save Current Layout" button at the top:
  - Opens a dialog for naming the template
  - Saves via `registerTemplate()` + `saveUserTemplates()`
- "Delete" button on user-created templates (shows only for user templates, not built-ins)
- Close button (X) in top-right

**Styling:**
- Use shadcn/ui components where possible (Dialog, Card, Badge, Button, Input)
- Use lucide-react icons
- The template cards should be in a responsive grid (3 columns on wide, 2 on medium)
- Selected card has a ring/border highlight
