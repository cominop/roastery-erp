## Spec Reference
From the project spec:
- "Stored calcs: Compute on save, not on read"

The calc_type 'stored' means the calculation result is pre-computed when the record is saved and stored in the DB. On read, the stored value is fetched — no re-computation.

## What to Build

### 1. SQL Migration (`server/sql/step-51-stored-calc-values.sql`)
Create `shared.calculated_field_values` table:
```sql
CREATE TABLE IF NOT EXISTS shared.calculated_field_values (
  id          UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  table_name  VARCHAR(255) NOT NULL,
  record_id   INTEGER      NOT NULL,
  field_name  VARCHAR(255) NOT NULL,
  value       TEXT,         -- stored as text, cast on read
  expression  TEXT,         -- snapshot for staleness detection
  computed_at TIMESTAMPTZ DEFAULT NOW(),
  created_at  TIMESTAMPTZ DEFAULT NOW(),
  updated_at  TIMESTAMPTZ DEFAULT NOW(),
  UNIQUE(table_name, record_id, field_name)
);
CREATE INDEX IF NOT EXISTS idx_calc_field_values_record
  ON shared.calculated_field_values (table_name, record_id);
```

### 2. Server Endpoints (`server/index.cjs`)

**POST /api/calculated-fields/compute-stored**
- Body: `{ table_name, record_id }`
- Fetches all `stored`-type calc fields for the table
- Fetches the actual record data from the ERP table
- Evaluates each expression via the existing Python evaluate_cli.py
- Upserts results into `shared.calculated_field_values`
- Returns: `{ stored_values: Record<string, any>, computed_at: string }`

**GET /api/calculated-fields/stored-values/:table/:recordId**
- Reads pre-computed values from `shared.calculated_field_values`
- No recomputation — just a DB read
- Returns: `{ stored_values: Record<string, any> }`
- Coerces numeric strings to numbers, passes through `#Error` markers

**Auto-trigger on save:** After POST /api/data/:table (insert) and PUT /api/data/:table/:id (update), if the table has stored calc fields, fire-and-forget a POST to compute-stored.

### 3. React API Client (`src/calculated-fields/api/calculatedFieldsApi.ts`)

### 4. React Hook (`src/calculated-fields/hooks/useCalculatedFields.ts`)

- Error handling: on stored fetch failure, return empty (fields display as null)
