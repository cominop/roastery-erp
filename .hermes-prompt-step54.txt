# Step 54: Audit Trail 3 — Apply triggers to all 68 ERP tables

## Objective
Apply the `shared.audit_log_trigger()` function (already created in Step 53) to all 68 tables in the `db_fcc_erp` schema. Each table gets an AFTER INSERT OR UPDATE OR DELETE trigger.

## Background
- Step 52 created `shared.audit_log` table + indexes
- Step 53 created `shared.audit_log_trigger()` PL/pgSQL function
- The trigger function handles INSERT/UPDATE/DELETE automatically using `to_jsonb()` for row snapshots
- The trigger reads `current_setting('app.changed_by_id', true)` set per-request by Express middleware

## What to build

### 1. Create migration SQL file
Create `server/sql/step-54-apply-audit-triggers.sql` that:
- Generates `CREATE TRIGGER trg_audit_<tablename>` statements for ALL 68 db_fcc_erp tables
- Each trigger: `AFTER INSERT OR UPDATE OR DELETE ON db_fcc_erp."<tablename>" FOR EACH ROW EXECUTE FUNCTION shared.audit_log_trigger()`
- Wraps in BEGIN/COMMIT transaction
- Uses DO $$ block with dynamic SQL to loop through tables (avoid manual listing)

### 2. Approach
Use a PL/pgSQL anonymous block (DO $$) to dynamically generate and execute the CREATE TRIGGER statements:

```sql
DO $$
DECLARE
  tbl TEXT;
BEGIN
  FOR tbl IN 
    SELECT tablename FROM pg_tables 
    WHERE schemaname = 'db_fcc_erp' AND LEFT(tablename, 1) != '_'
    AND NOT EXISTS (
      SELECT 1 FROM pg_trigger tg
      JOIN pg_class c ON c.oid = tg.tgrelid
      WHERE c.relname = tablename AND c.relnamespace = 'db_fcc_erp'::regnamespace
      AND tg.tgname LIKE 'trg_audit_%'
    )
  LOOP
    EXECUTE format(
      'CREATE TRIGGER trg_audit_%I AFTER INSERT OR UPDATE OR DELETE ON db_fcc_erp.%I FOR EACH ROW EXECUTE FUNCTION shared.audit_log_trigger()',
      tbl, tbl
    );
  END LOOP;
END $$;
```

This ensures idempotency — skips tables that already have audit triggers.

### 3. Verify
After applying, verify triggers exist:
```sql
SELECT tgname, relname FROM pg_trigger tg
JOIN pg_class c ON c.oid = tg.tgrelid
JOIN pg_namespace n ON n.oid = c.relnamespace
WHERE n.nspname = 'db_fcc_erp' AND tgname LIKE 'trg_audit_%'
ORDER BY relname;
```

### 4. Add an API endpoint to verify audit trigger status
Add a GET endpoint `/api/audit/triggers` that returns:
- Total ERP tables
- Tables WITH audit trigger
- Tables WITHOUT audit trigger

### 5. Test
Run the existing test: `npx vitest run server/__tests__/test_audit_trigger.cjs`
Also run: `npx vitest run server/__tests__/test_audit_log.cjs`
