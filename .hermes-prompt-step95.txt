## What to Build

### Goal
Create the actual .ods template files for the **5 most-used Access reports** and wire up the render pipeline so users can generate real PDF output from the UI.

### The 5 Reports (from seed data in shared.report_definitions)

1. **Invoice** (`invoice`) — `orders` source table, parameter: `order_id` (text)
   - Bands: title (rows 0-2), header (row 3), detail (row 4), summary (row 6), footer (rows 8-9)
   - Output formats: pdf, xlsx

2. **Invoice Summary** (`invoice-summary`) — `orders` source table, parameters: `date_from`, `date_to` (date)
   - Bands: title (rows 0-1), detail (row 2), summary (row 4), footer (row 6)
   - Output formats: pdf, csv, xlsx

3. **Credit Note** (`credit-note`) — `credit_notes` source table, parameter: `credit_note_id` (text)
   - Bands: title (rows 0-2), header (row 3), detail (row 4), summary (row 6), footer (rows 8-9)
   - Output formats: pdf, xlsx

4. **Customer Statement** (`customer-statement`) — `customers` source table, parameters: `customer_id` (lookup → customers), `date_from` (date), `date_to` (date)
   - Bands: title (rows 0-2), header (row 3), detail (row 4), summary (row 6), footer (row 8)
   - Output formats: pdf

5. **Inventory List** (`inventory-list`) — `inventory` source table, no parameters
   - Bands: title (rows 0-1), detail (row 2), footer (row 4)
   - Output formats: pdf, csv, xlsx

#### 2. Database/Data Fetch Script

Create `server/reports/data_fetcher.py` — a module that knows how to fetch data for each report type from the PostgreSQL database:

```python
def fetch_report_data(report_name: str, parameters: dict) -> dict:
    """Fetch data for a report and return the band data dict.
    
    Returns a dict with keys like 'title', 'detail', 'summary' etc.
    Each value is either a dict of marker->value (for single-value bands)
    or a list of dicts (for detail bands).
    """
```

The function should handle these 5 report types:
- **invoice**: Fetch order by order_id, get order_details for detail rows, compute subtotal/tax/total
- **invoice-summary**: Fetch orders within date range, group by customer, compute totals
- **credit-note**: Fetch credit note by credit_note_id, get credit_note_items for detail rows
- **customer-statement**: Fetch customer by customer_id, get all transactions within date range, compute running balance
- **inventory-list**: Fetch all inventory items, compute total value per item

#### 3. Fix the Render API Endpoint

Update `server/index.cjs` (the `POST /api/reports/:id/render` handler, around line 4184) to:
1. Call `data_fetcher.py` to get the data for the report
2. Pass the correct arguments to `renderer.py`:
