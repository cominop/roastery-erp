Implement Step 74: Visual Editor — Phase 3 — FormPropertiesPanel (form-wide settings: width, border, history, buttons)

## What to build

Create the `FormPropertiesPanel` component for the Visual Editor. This is a settings/properties panel that appears when no individual control is selected, showing form-wide configuration options: form width, border style, navigation buttons, and recent form history.

### Features required

1. **Form Design section** — editable form-wide settings:
   - Width (twips numeric input, default 14400)
   - Border style (dropdown: Sizable, Dialog, None, Thin)
   - Navigation Buttons toggle
   - Record Selectors toggle
   - Dividing Lines toggle  
   - Scroll Bars (dropdown: Neither, Horizontal, Vertical, Both)
   - Auto Resize toggle
   - Min Max Buttons toggle
   - Close Button toggle

2. **Recent Forms section** — clickable list of recently opened forms:
   - Shows last 10 forms with form name
   - Clicking a form name navigates to it (via `onNavigate` callback)
   - "→" arrow icon indicates clickable
   - Empty state: "No recent forms" when list is empty

3. **Form History section** — version history of the current form:
   - Shows version number, date, and change description
   - Latest version at top
   - Read-only display

4. **Section collapsibility** — each section can be collapsed/expanded via a clickable header

### Component API

```typescript
interface FormPropertiesPanelProps {
  /** Current form-level settings */
  formSettings: FormDesignSettings;
  /** Callback when any form setting changes */
  onSettingsChange: (settings: Partial<FormDesignSettings>) => void;
  /** Recent forms list (max 10) */
  recentForms: RecentFormItem[];
  /** Called when a recent form is clicked */
  onNavigate: (formName: string) => void;
  /** Form version history */
  formHistory: FormHistoryEntry[];
  disabled?: boolean;
}

interface FormDesignSettings {
  /** Form width in twips (default: 14400) */
  width: number;
  /** Border style */
  border: 'sizable' | 'dialog' | 'none' | 'thin';
  /** Show navigation buttons at bottom */
  showNavigationButtons: boolean;
  /** Show record selectors */
  showRecordSelectors: boolean;
  /** Show dividing lines between sections */
  showDividingLines: boolean;
  /** Scroll bar visibility */
  scrollBars: 'neither' | 'horizontal' | 'vertical' | 'both';
  /** Auto-resize form to fit content */
  autoResize: boolean;
  /** Show minimize/maximize buttons */
  showMinMaxButtons: boolean;
  /** Show close button */
  showCloseButton: boolean;
}

interface RecentFormItem {
  name: string;
  caption?: string;
}

interface FormHistoryEntry {
  version: number;
  date: string;
  description: string;
}
```

### Implementation approach

1. **State management**: Fully controlled via `formSettings` + `onSettingsChange`. Use local state for UI-only concerns like collapsed sections.

2. **Section collapsing**: Local state tracking which sections are collapsed. Each section header is a clickable <button> with a ChevronDown/ChevronRight icon.

3. **Form settings**: Each setting is a labelled row with the appropriate input control. Group them with a section header "Form Design".

4. **Recent Forms**: Simple list with hover effect. Each row shows the form name + caption and a → arrow icon. Click calls `onNavigate(formName)`.

5. **Form History**: Version entries displayed as a list. Simple text formatting: "v{version} - {date} - {description}".
