## What to Build

### 1. API Endpoints — Add to `server/index.cjs`

Add `/api/metadata/export` route:
- Method: POST
- Body: `{ types: string[], description?: string }` — types is an array of metadata types to include (forms, fields, events, nav_tree, permissions, reports, templates, settings)
- Action: Runs `node server/metadata-exporter.cjs` to get current metadata, then runs `node server/metadata-packager.cjs` to create a .zip archive
- Returns: `{ success: true, filename: string, path: string, size_bytes: number }`

Add `/api/metadata/import` route:
- Method: POST
- Content-Type: multipart/form-data
- Field: `file` — .zip archive
- Action: 
  1. Save uploaded file to temp dir
  2. Run `node server/metadata-importer.cjs --archive <path>` to validate
  3. Create backup via `node server/metadata-backup.cjs --reason pre_import`
  4. Run UPSERT via `node server/metadata-importer-upsert.cjs --archive <path>`
  5. Return result with stats
- Returns: `{ success: true, stats: { forms_added, forms_updated, fields_added, fields_updated, events_added, events_updated }, backup_id: string }`
