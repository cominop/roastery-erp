Implement Step 72: Visual Editor — Phase 2 — ColumnLayoutConfig (columns, label size, panel toggle)

## What to build

Create the `ColumnLayoutConfig` component for the Visual Editor. This is a display options panel that configures the form grid layout. It sits beside the FieldPicker component.

### Mockup
```
┌─ Display Options ────────────────────────────┐
│  Columns:  [1 ▼]    (1, 2, 3, 4)             │
│  Label size: [Medium ▼]                      │
│    (xSmall / Small / Medium / Large / xLarge) │
│  ☑ In panel (inset effect)                   │
└──────────────────────────────────────────────┘
```

### Component API
```typescript
interface ColumnLayoutConfigProps {
  columns: number;
  labelSize: LabelSize;
  inPanel: boolean;
  onChange: (config: ColumnLayoutConfigProps) => void;
}

type LabelSize = 'xsmall' | 'small' | 'medium' | 'large' | 'xlarge';
```

### Key guidelines
- Use proper shadcn Select pattern: `<Select><SelectTrigger><SelectValue /></SelectTrigger><SelectContent><SelectItem value="1">1</SelectItem>...</SelectContent></Select>`
- Use proper shadcn Checkbox pattern: `<div className="flex items-center gap-2"><Checkbox id="in-panel" checked={inPanel} onCheckedChange={...} /><Label htmlFor="in-panel">In panel (inset effect)</Label></div>`
- The component should be a controlled component (reads from props, fires onChange)
- Keep the component self-contained (no external state management dependencies)
