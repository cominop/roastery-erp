### Component Design

The FieldEditorDialog should:
- Accept `field: FieldDefinition | null` (null = creating new, non-null = editing existing)
- Accept `onSave: (field: FieldDefinition) => void` and `onCancel: () => void`
- Accept `tableFields?: string[]` for lookup field dropdown options
- Accept `open: boolean` to control visibility
- Use shadcn/radix Dialog component for the modal
- Use shadcn/radix Tabs component for the three tabs
- Show FILE/IMAGE config sub-panel on the Interface tab when type is FILE or IMAGE
- Auto-generate `name` from `caption` when creating (lowercase, spaces→underscores)
- Validate: caption required, name required (snake_case), type required
- Show size field only for TEXT type
- The Lookup tab should only be visible when type is 'LOOKUP'

### Types to define

```typescript
// In types-field.ts
export type FieldType =
  | 'TEXT' | 'INTEGER' | 'FLOAT' | 'CURRENCY'
  | 'DATE' | 'DATETIME' | 'BOOLEAN' | 'LONGTEXT'
  | 'FILE' | 'IMAGE' | 'LOOKUP';

export interface FieldDefinition {
  id: string;
  caption: string;
  name: string;
  type: FieldType;
  size?: number;
  defaultValue?: string;
  required: boolean;
  readOnly: boolean;

  // Lookup (when type is LOOKUP)
  lookupItem?: string;
  lookupField?: string;
  lookupField2?: string;
  lookupField3?: string;
  masterField?: string;
  typeahead?: boolean;
  lookupValueList?: string[];

  // Interface overrides
  mask?: string;
  textArea?: boolean;
  doNotSanitize?: boolean;
  alignment?: 'left' | 'center' | 'right';
  placeholder?: string;
  help?: string;

  // File/Image
  accept?: string[];
  viewWidth?: number;
  viewHeight?: number;
  editWidth?: number;
  editHeight?: number;
  captureFromCamera?: boolean;
}
```
