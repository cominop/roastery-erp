## What to build

You need to create two components for configuring view-form (datasheet) table columns:

### 1. `src/visual-editor/TableFieldPicker.tsx`

A two-list selector (like the existing FieldPicker) but tailored for view-form/datasheet column configuration. Each selected column has a per-column **width** input (in pixels).

**Mockup from spec:**
```
┌─ Selected Columns ────┐  ┌─ Available Columns ┐
│  Order #      (80px)  │  │  Internal ID      │
│  Customer    (150px)  │  │  Created At       │
│  Total       (100px)  │  │  Deleted Flag     │
│  Status      (100px)  │  │  Notes            │
│  Date        (120px)  │  │                   │
└────────────────────────┘  └────────────────────┘
```

**Key differences from the existing FieldPicker:**
- Each selected column has a width number input (inline, text input with px suffix)
- Columns are always "visible" (no visibility checkbox per column — that's for edit forms)
- Support column sorting via drag or inline up/down arrows
- Same "move between lists" and "reorder" behavior as FieldPicker

**Props:**
```typescript
export interface TableColumnItem {
  name: string;
  type: string;
  width?: number;           // column width in px (default: 100)
}

export interface TableFieldPickerProps {
  availableFields: TableColumnItem[];
  selectedFields: TableColumnItem[];
  onChange: (selected: TableColumnItem[]) => void;
  disabled?: boolean;
}
```

**Behaviour:**
- Left list: available columns (all fields not yet selected)
- Right list: selected columns in display order, each with inline width input
- Arrow buttons: move selected between lists
- Up/down buttons: reorder within right list
- Width input: text input that updates the column's width property on blur
- Empty states: "All fields selected" / "No columns selected"
- Search/filter for both lists (same as FieldPicker)
- Type color coding same as FieldPicker (number=emerald, text=blue, date=violet, boolean=amber)

### 2. `src/visual-editor/TableOptionsPanel.tsx`

A panel for view-form table options, following the same visual pattern as FormPropertiesPanel.

**Options from spec:**

| Option | Control | Description |
|--------|---------|-------------|
| Multiple selection | Checkbox | Checkbox column for bulk select |
| Dblclick edit | Checkbox | Double-click opens edit form |
| Number of rows | Number input | Fixed row count |
| Height | Number input (px) | Or auto-calculate |
| Row lines | Number input | Lines per row (0 = auto) |
| Selected row lines | Number input | Min lines for selected row |
| Freeze columns | Number input | Frozen left columns |
| Sort fields | Multi-picker | Clickable column headers |
| Summary fields | Multi-picker | Footer sums / counts |

**Props:**
```typescript
export interface TableOptions {
  multiSelect: boolean;
  dblclickEdit: boolean;
  numRows: number;          // 0 = auto
  height: number;           // px, 0 = auto
  rowLines: number;         // 0 = auto
  selectedRowLines: number;
  freezeColumns: number;    // 0 = none
  sortFields: string[];     // field names
  summaryFields: string[];  // field names
}

export interface TableOptionsPanelProps {
  values: TableOptions;
  onChange: (changes: Partial<TableOptions>) => void;
  availableFields: TableColumnItem[];
  disabled?: boolean;
}
```

**Visual style:**
- Same compact layout as FormPropertiesPanel (11px fonts, small inputs, steppers with +/- buttons)
- Use lucide icons for each section header
- Divided sections with border-t separators
- Sort fields and Summary fields use a small inline FieldPicker or a multi-select popover (simplest approach: use a text-area-like list)
