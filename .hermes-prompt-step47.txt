Implement Step 47 — Admin editor UI for Calculated Fields

## What to Build

Create the admin editor UI for defining calculated fields. This is Step 6 of the Calculated Fields track (spec at "Roastery ERP - SPEC - Calculated Fields.md" in the Obsidian vault).

### Files to create in `src/calculated-fields/`:

1. **CalculatedFieldEditor.tsx** — Main admin form that loads by table, shows existing calculated fields as a list/table, and lets the admin create/edit/delete them. Must include:
   - A table selector dropdown at the top to choose which DB table to manage
   - A list of existing calculated fields for that table (fetched from API)
   - "Add Calculated Field" button
   - Inline or dialog-based editing for each field
   - Delete with confirmation
   - All fields from the CalculatedField schema: name, caption, calcType, expression, dataType, dependsOn, readOnly, refreshOn, format, decimals, visible, sortable, filterable

2. **ExpressionEditor.tsx** — Expression input with:
   - A textarea/code editor for the expression string
   - Syntax highlighting for field references ({field_name}) and function calls
   - Autocomplete suggestions for available fields from the selected table
   - A "Detect Dependencies" button that calls the API's detect-dependencies endpoint
   - Display auto-detected dependencies inline below the editor

3. **FunctionPicker.tsx** — Function reference panel showing:
   - A grid/list of all supported functions: SUM, COUNT, AVG, MIN, MAX, IF, LOOKUP, DATEDIFF, TODAY, NOW, CONCAT, UPPER, LOWER, ROUND, COALESCE
   - Each function shows its signature and a short description
   - Clicking a function inserts it into the ExpressionEditor at cursor position
   - Filter/search box to quickly find functions

### Which components exist already

- `src/calculated-fields/api/calculatedFieldsApi.ts` — Full CRUD API client + detectDependencies endpoint
- `src/calculated-fields/schema/calculatedFieldSchema.ts` — TypeScript interfaces (CalculatedField, DependencyResult)
- `server/` side: Python parser, evaluator, function library already implemented in steps 42-44

### Available API endpoints (already working)

- GET /api/calculated-fields?table_name=X — list fields for a table
- GET /api/calculated-fields/:id — single field
- POST /api/calculated-fields — create field
- PUT /api/calculated-fields/:id — update field
- DELETE /api/calculated-fields/:id — delete field
- POST /api/calculated-fields/detect-dependencies — detect deps from expression
