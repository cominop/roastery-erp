### 1. Create `src/reports/components/ParameterForm.tsx`

A component that takes a `parameters: ReportParameter[]` array and auto-generates form fields:

```
┌─ Run Report: [report caption] ─────────────────┐
│                                                  │

│  ┌─────────────────────┐  ┌─────────────────────┐│

│  └─────────────────────┘  └─────────────────────┘│
│                                                  │
│  Customer (lookup)                                │
│  ┌─────────────────────────────────────────────┐ │
│  │ [Search customers...                    ▼]  │ │
│  └─────────────────────────────────────────────┘ │
│                                                  │
│  Department (select)                              │
│  ┌─────────────────────────────────────────────┐ │
│  │ [Select department...                   ▼]  │ │

│                                                  │

│  └─────────────────────────────────────────────┘ │
│                                                  │
│         [Cancel]           [Generate Report]     │
└──────────────────────────────────────────────────┘
```

**Props interface:**
```typescript
interface ParameterFormProps {
  report: ReportDefinition;
  open: boolean;
  onOpenChange: (open: boolean) => void;
  onGenerate: (params: Record<string, unknown>) => void;
}
```

**Field rendering logic (parameter type → component):**

| Parameter type | Renders as | Behavior |
|---|---|---|
| `text` | `<Input>` | Text input with optional placeholder |
| `number` | `<Input type="number">` | Number input with step=any |
| `date` | Date picker (Popover + Calendar) | Single date selection. Use `date-fns` format. |
| `boolean` | `<Switch>` with label | Toggle. |
| `select` | `<Select>` | Dropdown from `parameter.options[]`. If `required` is false, add a "— None —" option. |
| `lookup` | Searchable `<Select>` with dynamic options | On focus/open, call a search API to populate options. Use the report's `source_table` as context. For lookups, query `/api/lookup/{table}?search=...` endpoint. Show loading spinner while fetching. Minimum 2 characters to search. |

**State management:**
- Use a `useState<Record<string, unknown>>` map keyed by `parameter.name`
- Initialize defaults from `parameter.default`
- Validate `required` fields before enabling the "Generate Report" button
- Show validation errors inline (red text under the field)

**Date-range special handling:**
If two consecutive parameters both have `type: 'date'` and names like `*_start`/`*_from` and `*_end`/`*_to` (matching pattern), render them side by side as a date range group.

### 2. Create `src/reports/components/RunReportDialog.tsx`

A dialog wrapper that:
1. Accepts a `report: ReportDefinition` and `open`/`onOpenChange` props
2. Shows the ParameterForm inside a Dialog
3. On generate, calls `fetch('/api/reports/${report.id}/render', { method: 'POST', body: JSON.stringify(params) })` to trigger the render
4. Shows a loading spinner while generating
5. On success, triggers a file download from the response blob
6. On error, shows an error message inside the dialog
7. Closes the dialog after download starts
