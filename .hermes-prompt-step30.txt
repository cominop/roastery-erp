### 1. Database — Create `db_fcc_erp.filter_presets` table
Add a SQL migration script at `server/sql/step-30-filter-presets.sql`:
```sql
CREATE TABLE IF NOT EXISTS db_fcc_erp.filter_presets (
  id SERIAL PRIMARY KEY,
  name VARCHAR(255) NOT NULL,
  table_name VARCHAR(255) NOT NULL,
  filters JSONB NOT NULL DEFAULT '[]',
  filter_logic VARCHAR(3) NOT NULL DEFAULT 'AND',
  user_id INTEGER NOT NULL DEFAULT 1,
  shared BOOLEAN NOT NULL DEFAULT false,
  sort_order INTEGER NOT NULL DEFAULT 0,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

CREATE INDEX IF NOT EXISTS idx_filter_presets_user_id ON db_fcc_erp.filter_presets(user_id);
CREATE INDEX IF NOT EXISTS idx_filter_presets_shared ON db_fcc_erp.filter_presets(shared);
CREATE INDEX IF NOT EXISTS idx_filter_presets_table_name ON db_fcc_erp.filter_presets(table_name);
```

Run it via a terminal call: `psql -d polyaccess -f server/sql/step-30-filter-presets.sql`

### 2. Server — API Endpoints in `server/index.cjs`
Add the following endpoints BEFORE the `// ─── Start ───` line:

**GET /api/filter-presets**
- Query params: `table_name` (optional), `user_id` (default 1)
- Returns: user's own presets + shared presets, ordered by sort_order
- Filter: `WHERE (user_id = $1 OR shared = true) AND (table_name = $2 OR $2 IS NULL)`

**POST /api/filter-presets**
- Body: `{ name, table_name, filters, filter_logic, user_id, shared }`
- Insert and return the created record
- Validate: name and table_name required, filters must be valid JSON array

**PUT /api/filter-presets/:id**
- Body: any updatable fields (name, filters, filter_logic, shared, sort_order)
- Only allow updating presets owned by the user (check user_id matches)
- Return 403 if not owner
- Set updated_at = NOW()

**DELETE /api/filter-presets/:id**
- Only allow deleting presets owned by the user
- Return 403 if not owner
- Return 404 if not found
