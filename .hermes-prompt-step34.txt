## Task

Add a permission middleware to the Express server that checks table-level permissions on EVERY API call. The middleware should:

1. **Create a permission middleware module** at server/permission-middleware.cjs that:
   - Exports a function `checkPermission(tableName, action, userRoleIds, companyId)` that queries shared.table_permissions and returns true/false
   - Exports a function `applyRowFilter(tableName, userRoleIds, companyId)` that fetches row_filters for any of the user's roles and returns a SQL WHERE fragment
   - Exports an Express middleware factory `permissionGuard(tableNameExtractor, actionMap)` that:
     - Extracts the table name from the request (usually req.params.table)
     - Maps the HTTP method to an action (GET→select, POST→insert, PUT→update, DELETE→delete)
     - Queries table_permissions for the current user's roles
     - Returns 403 if none of the user's roles grant the required action
     - Calls next() if permitted

2. **For now, use a placeholder auth system** — since there's no real authentication yet, extract user info from:
   - A header `X-User-Id` (integer employee ID)
   - A header `X-Company-Id` (integer, defaults to 1)
   - Fall back to user_id=1, company_id=1 if headers are missing
   - Lookup the user's roles from shared.user_roles

3. **Apply the middleware** to the following routes in server/index.cjs:
   - GET /api/data/:table — requires can_select
   - POST /api/data/:table — requires can_insert
   - PUT /api/data/:table/:id — requires can_update
   - DELETE /api/data/:table/:id — requires can_delete
   - GET /api/forms — requires can_select on 'shared.objects'
   - POST /api/lookup — requires can_select on the tables referenced in the SQL
   - GET /api/schema/:table — requires can_select

4. **Handle the admin role** — admin (role name 'admin') should bypass all permission checks.

5. **Seed some basic table_permissions** so the system doesn't 403 on everything:
   - Admin gets all permissions on all tables
   - data-entry gets select/insert/update on orders, order_details, customers, products
   - read-only gets select on all tables

6. **Keep it simple** — this is middleware, not a full auth system. Don't change the frontend. Don't add tests yet. Just the server-side enforcement.
