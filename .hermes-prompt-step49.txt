## What to Build

### 1. `useCalculatedFields` hook (`src/calculated-fields/hooks/useCalculatedFields.ts`)
A React hook that:
- Accepts a `tableName: string | undefined` parameter
- Fetches all calculated fields for that table via `fetchCalculatedFields(tableName)` from the API client
- Accepts a `record: Record<string, unknown> | null` parameter (the current record context)
- For each calculated field where `refreshOn === 'read'`:
  - Calls `testExpression(field.expression, recordValues)` to evaluate the expression against the current record's field values
  - Caches results to avoid re-evaluating when deps haven't changed
  - Returns a map of `{ [fieldName]: computedValue }`
- Auto-refreshes when any dependency field in the record changes (useEffect with dependency tracking)
- Handles loading and error states
- Memoizes to avoid unnecessary re-renders

```typescript
interface UseCalculatedFieldsResult {
  computedValues: Record<string, any>;
  loading: boolean;
  errors: Record<string, string>;
}

function useCalculatedFields(tableName: string | undefined, record: Record<string, unknown> | null): UseCalculatedFieldsResult
```

Key considerations:
- Use `fetchCalculatedFields(tableName)` from the API client to get field definitions
- Use `testExpression(expression, values)` to evaluate each field's expression against the record context
- Cache results per record key to avoid redundant API calls
- Only re-evaluate when the dependent fields change (use `dependsOn` from the field definition)
- The hook should debounce rapid record changes (e.g., during typing) to avoid overwhelming the API

### 2. `CalculatedFieldValue` component (`src/calculated-fields/CalculatedFieldValue.tsx`)
A component that renders a computed calculated field value with formatting:
- Accepts: `value: any`, `field: CalculatedField` (the definition)
- If value is null/undefined, display nothing or a placeholder
- Apply formatting: prefix, suffix, decimals, format string
- Render according to dataType: text, number (with decimals/format), currency ($ prefix + decimals), boolean (Yes/No), date
- Display as a styled read-only value (gray background, italic or different text color to indicate computed)

### 3. Integrate into FormRenderer (`src/components/FormRenderer.tsx`)
The FormRenderer already renders controls with field bindings. For each control:

1. In `renderControl`, after resolving the field and value:
   - Check if the field has a calculated field definition (from the hook's data)
   - If yes, display a `CalculatedFieldValue` instead of the editable control
   - The field should show the computed value and be visually distinct (read-only styling)

2. Add the `useCalculatedFields` hook call in the FormRenderer:
   - After the `table` is resolved from the record-source
   - Pass `recordSource.current` as the record context
   - Merge computed values into the display context

3. Auto-refresh behavior:
   - When `recordSource.current` changes, the hook's dependency tracking picks it up
   - If the record's field values change (e.g., user edits a dep), the calculated field auto-refreshes
   - The computed value appears read-only (editing disabled) with visual distinction
