## Step 71 — Visual Editor 1: FieldPicker two-list selector

Build the FieldPicker component for the Visual Editor according to the spec at `Roastery ERP - SPEC - Visual Editor.md` (Phase 1).

### Objective
Create a reusable `FieldPicker` component that lets users curate an ordered subset of fields from a database table. This is the core interaction for building form layouts.

### Mockup
```
┌─ Selected Fields ──┐  ┌─ Available Fields ┐
│  Customer Name     │  │  Created At       │
│  Email             │  │  Last Modified    │
│  Phone             │  │  Notes            │
│  Address           │  │  Internal ID      │
│                    │  │  Deleted Flag     │
└────────────────────┘  └───────────────────┘
     ▲ ▲ ▼ ▼  (move up/down/left/right)
```

### Props
```typescript
interface FieldRef {
  fieldId: string;
  visible: boolean;
  overrideLabel?: string;
  inputType?: 'text' | 'textarea' | 'dropdown' | 'checkbox' | 'datepicker' | 'lookup-picker';
  width?: 'full' | 'half' | number;
  required?: boolean;
  readOnly?: boolean;
  placeholder?: string;
  help?: string;
  textAreaRows?: number;
  mask?: string;
}
```
- `fields: FieldDef[]` — all available fields for the table
- `selected: FieldRef[]` — currently selected + ordering
- `onChange: (selected: FieldRef[]) => void`

### Behaviour
- Left list: selected fields in display order
- Right list: all fields not yet selected
- Arrow buttons ( → / ← ): move selected field between lists
- Up/Down buttons: reorder within left list
- Keyboard shortcut: Space toggles the focused field between lists
- Each selected field row shows: checkbox (visible/hidden), label override input, width dropdown

### Testing
Write vitest unit tests that verify:
1. All fields appear in available list initially
2. Clicking → moves selected field to selected list
3. Clicking ← moves selected field back to available
4. Up/Down reorders within selected list
5. onChange fires with updated array after each operation
6. Space key toggles focused field between lists
7. Checkbox toggles visible state on selected field rows
8. Label override input updates the FieldRef
9. Width dropdown selects correctly
10. Empty state renders properly when no fields provided
