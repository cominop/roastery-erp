## What to Build

### 1. Retention Policy Table (SQL)

Create /home/fcc-student/Desktop/_DEV/roastery-ui/server/sql/step-59-retention-policy.sql:
```sql
CREATE TABLE IF NOT EXISTS shared.audit_retention_policy (
  id                UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  table_name        TEXT,              -- null = applies to all tables
  full_retention    INTERVAL DEFAULT '1 year',
  summary_retention INTERVAL DEFAULT '7 years',
  auto_prune        BOOLEAN DEFAULT true,
  created_at        TIMESTAMPTZ DEFAULT NOW(),
  updated_at        TIMESTAMPTZ DEFAULT NOW()
);
```

### 2. API Endpoints (in server/index.cjs)

Add these routes near the other audit endpoints:
- GET /api/audit/retention — list all retention policies
- POST /api/audit/retention — upsert a retention policy row
- DELETE /api/audit/retention/:id — remove a per-table override
- POST /api/audit/prune — manually trigger prune job (returns count of deleted rows)

### 3. Prune Job Script

Create /home/fcc-student/Desktop/_DEV/roastery-ui/server/prune-audit.cjs:
- Load all retention policies
- For each table, delete entries older than full_retention
- Skip per-table overrides when processing global
- Set undo_available = false before deletion
- Batch deletes of 1000 rows
- Return { deleted_count, tables_affected }
