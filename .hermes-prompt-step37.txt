## What to Build

Create a Role Manager UI that allows admins to CRUD roles and assign users to roles.

### 1. API Endpoints (server/index.cjs)

Add these endpoints:

**GET /api/roles** — list all roles
- Returns: [{id, name, caption, is_system, created_at}]
- Ordered by name

**POST /api/roles** — create a new role
- Body: {name, caption, copy_from_role_id?}
- If copy_from_role_id is provided, clone all table_permissions, field_permissions, and row_filters from that role
- Validate name is unique

**PUT /api/roles/:id** — update role caption/name
- Body: {name?, caption?}
- is_system roles: only caption can be changed, not name

**DELETE /api/roles/:id** — delete a role (cascade)
- Reject deletion of is_system roles with 403
- Respond with {deleted: true}

**GET /api/roles/:id/users** — list users assigned to a role
- Returns: [{user_id, employee_name, email, assigned_at}]
- Join shared.user_roles with db_fcc_erp.employees

**POST /api/roles/:id/users** — assign users to a role
- Body: {user_ids: [uuid, ...]}
- Upsert: add new assignments, remove any not in the list
