## What to build

### 1. `src/controls/hooks/useLookupSearch.ts`
A React hook that provides debounced typeahead search:

```typescript
interface LookupResult {
  id: string | number;
  displayValue: string;
  raw: Record<string, unknown>;
}

function useLookupSearch(lookupItem: string): {
  searchTerm: string;
  setSearchTerm: (term: string) => void;
  results: LookupResult[];
  loading: boolean;
  error: string | null;
  search: (term: string) => void; // immediate search (for browser)
}
```

- Debounce at 300ms (min 2 chars to trigger)
- Uses the existing API client's `runLookup()` for search — SELECT id, display_fields FROM lookupItem WHERE display_field ILIKE '%term%' LIMIT 20
- The lookupItem is the table name. The first display field is lookupField from the FieldDefinition, then lookupField2, lookupField3.
