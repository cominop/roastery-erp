## What Needs to Be Built

### 1. Backend: New API endpoint — field-level permissions lookup

Add a new POST endpoint at `/api/permissions/field-access` in `server/index.cjs`:

- Accepts: `{ table: string }`
- Queries `shared.field_permissions` for the current user's roles + table
- Returns: `{ access: Record<string, 'hidden' | 'readonly' | 'readwrite'> }`
  - Maps each field_name to its access level
- Admin bypass: if user is admin, return `{ access: {} }` (no restrictions, meaning all fields are readwrite by default)
- If no field_permissions rows exist for the user's roles on this table, return `{ access: {} }` (default is readwrite)
- Edge case: if `can_read = false` in field_permissions → `'hidden'`
- Edge case: if `can_read = true` and `can_write = false` → `'readonly'`
- Edge case: if `can_read = true` and `can_write = true` → `'readwrite'`
- If a user has multiple roles, the *most permissive* access wins across all their roles (hidden < readonly < readwrite) — i.e., if one role says readonly and another says hidden, use readonly. If one says readonly and another says readwrite, use readwrite.

### 5. Backend: Server-side `filter_fields` function

Add to `server/permission-middleware.cjs` or as middleware in `server/index.cjs`:

```javascript
async function getFieldPermissions(tableName, userRoleIds, companyId) {
  if (!userRoleIds || userRoleIds.length === 0) return {};

  const { rows } = await pool.query(
    `SELECT field_name, can_read, can_write
     FROM shared.field_permissions
     WHERE role_id = ANY($1::int[])
       AND table_name = $2
       AND company_id = $3`,
    [userRoleIds, tableName, companyId]
  );

  // Merge: most permissive wins (hidden < readonly < readwrite)
  const accessLevel = { hidden: 0, readonly: 1, readwrite: 2 };
  const result = {};
  for (const row of rows) {
    let access;
    if (!row.can_read) access = 'hidden';
    else if (!row.can_write) access = 'readonly';
    else access = 'readwrite';
    
    const current = result[row.field_name];
    if (current === undefined || (accessLevel[access] > accessLevel[current])) {
      result[row.field_name] = access;
    }
  }
  return result;
}
```

Export it from the middleware module.

CREATE TABLE shared.field_permissions (

def filter_fields(fields, table_name, user):
    perms = FieldPermission.query.filter_by(
        role_id=user.role_id, table_name=table_name
    ).all()
    access_map = {p.field_name: p.access for p in perms}
    return [
