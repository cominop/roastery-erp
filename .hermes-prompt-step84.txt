## What to Build

### 1. `server/differ.py` — Python module to diff two metadata sets

This module compares two extracted metadata directories (current DB state vs. imported archive) and produces a structured diff report.

**Location:** `server/differ.py`

**API** (the module should be importable and callable from the Express server via child_process):

```python
def diff_metadata(current_dir: str, incoming_dir: str) -> dict:
    """
    Compare two metadata export directories.
    
    Args:
        current_dir: Path to the current metadata (exported live from DB)
        incoming_dir: Path to the incoming metadata (from the archive being imported)
    
    Returns:
        dict with the following structure:
        {
            "summary": {
                "forms": {"added": 0, "removed": 0, "changed": 0, "unchanged": 0},
                "fields": {"added": 0, "removed": 0, "changed": 0, "unchanged": 0},
                "events": {"added": 0, "removed": 0, "changed": 0, "unchanged": 0},
                "nav_tree": {"added": 0, "removed": 0, "changed": 0, "unchanged": 0},
                "permissions": {"added": 0, "removed": 0, "changed": 0, "unchanged": 0},
                "reports": {"added": 0, "removed": 0, "changed": 0, "unchanged": 0},
                "settings": {"added": 0, "removed": 0, "changed": 0, "unchanged": 0}
            },
            "details": {
                "forms": [
                    {
                        "name": "CustomerForm",
                        "status": "added|removed|changed|unchanged",
                        "changes": ["field 'phone' caption changed from 'Phone' to 'Mobile'", ...]
                    },
                    ...
                ]
            }
        }
    """
```

**How to compare:**
- For each definition file type (forms.json, fields.json, events.json, etc.), compare the JSON arrays entry-by-entry.
- Two entries are "unchanged" if their JSON serialization is identical.
- If they differ, produce a human-readable list of what changed (field-level diff).
- Use `json.dumps(entry, sort_keys=True, default=str)` for comparison.
- For the change description, do a simple key-by-key comparison of the two dicts and report which keys differ and what the old/new values are.

**CLI entry point:** The module should also be runnable as a script:
```bash
python3 server/differ.py --current /path/to/current --incoming /path/to/incoming --output diff.json
```

### 2. API endpoint — `GET /api/metadata/diff`

Add a new route to `server/index.cjs`:

```
GET /api/metadata/diff?archive=<path-to-archive>
```

This endpoint:
1. Exports the current metadata to a temp directory (call `node server/metadata-exporter.cjs` or do the export inline)
2. Extracts the specified archive to a temp directory
3. Calls `python3 server/differ.py` to compare the two
4. Returns the diff JSON

Since the existing exporter is a Node.js script, create a Node.js wrapper at `server/metadata-differ.cjs` that:
1. Exports current metadata to a temp dir
2. Extracts the archive to a temp dir
3. Calls `python3 server/differ.py --current <tmp1> --incoming <tmp2>`
4. Captures the output and returns it

**Implementation details:**
- Use the existing shadcn/ui components: `Card`, `Badge`, `ScrollArea`, `Accordion` (or plain collapsible sections)
- Fetch the diff from `GET /api/metadata/diff?archive=<path>` on mount
- Show a loading state while fetching
- Show an error state if the diff fails
- Group changes by type (forms, fields, events, etc.) in collapsible sections
- Each changed item shows a short summary of what changed
- Use color coding: green for added, red for removed, amber for changed
- Include a filter dropdown to show: All, Added only, Removed only, Changed only
- The "Proceed with Import" button calls `onConfirm` (which will be wired up later when the ImportDialog is built in Step 88)
