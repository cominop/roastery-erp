## What to Build

Create `src/reports/ReportManager.tsx` — a full report listing page that:

1. **Fetches data on mount:** calls `fetchReports()` and `fetchReportCategories()` from the reportsApi
2. **Groups reports by category** — categories are like "Financial", "Inventory", "Production", "Other"
3. **Search bar** at the top — filters reports by name/caption/description as user types (client-side)
4. **Filter dropdowns:**
   - Category dropdown (populated from `fetchReportCategories()` + "All" option)
   - Format dropdown (PDF, CSV, XLSX, HTML as options + "All")
5. **Grouped list** — each category is a section header with an emoji icon and count, followed by report cards
6. **Report card** for each report showing:
   - Report name (caption)
   - Description (if any)
   - Format badges (PDF, CSV, XLSX, HTML) as small colored badges
   - A "Run" button to generate the report
7. **Empty state** — "No reports found" message when filters match nothing
8. **Loading state** — spinner/skeleton while data loads
9. **Error state** — error message with retry button

### Category icons
