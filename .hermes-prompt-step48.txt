## Objective
Create a functional test panel that allows administrators to test calculated field expressions with sample values before saving the field definition.

## What to Build

### 1. Server-side: Expression Evaluator CLI + API Endpoint

Create a new CLI script `server/calculated_fields/evaluate_cli.py` following the exact same pattern as `detect_deps_cli.py`:

```python
# evaluate_cli.py
# Accepts --expression <expr> and --values <json-string>
# Where values is a JSON object like {"sell_price": 15.00, "cost_price": 8.50}
# Calls evaluate_expression from the evaluator
# Prints JSON result: {"result": 43.33} or {"error": "message"}
```

Then add a new API endpoint in `server/index.cjs` (at line ~1518, before the event engine section):

```
POST /api/calculated-fields/test-expression
Body: { expression: string, values: Record<string, any> }
```

The endpoint should:
- Validate input (expression is required string, values is optional object)
- Call the Python CLI with the expression and values as JSON
- Return `{ result: any }` on success
- Return `{ error: string }` on failure with appropriate status code
- Use a 10-second timeout (expressions are simple)
- Follow the exact same pattern as the existing `POST /api/calculated-fields/detect-dependencies` endpoint

### 2. Client-side: API function in `calculatedFieldsApi.ts`

Add to `src/calculated-fields/api/calculatedFieldsApi.ts`:

```typescript
interface TestExpressionResult {
  result: any;
}

export function testExpression(
  expression: string,
  values: Record<string, any>,
): Promise<TestExpressionResult> {
  return request<TestExpressionResult>('/calculated-fields/test-expression', {
    method: 'POST',
    body: JSON.stringify({ expression, values }),
  });
}
```

### 3. Create `TestPanel.tsx` component

Create `src/calculated-fields/admin/TestPanel.tsx`. This is a modal/dialog component for testing expressions with sample values.

**Layout** (from the spec, section 8.2):
```
┌─ Test Expression ───────────────────────────┐
│  Expression: ({sell_price} - {cost_price})   │
│              / {sell_price} * 100            │
│                                              │
│  ┌─ Test Values ──────────────────────────┐  │
│  │  sell_price = [15.00       ]            │  │
│  │  cost_price = [8.50        ]            │  │
│  │  ─────────────────────────────────────  │  │
│  │  Result: 43.33%                         │  │
│  └────────────────────────────────────────┘  │
│                                              │
│  [Run Test]  [Close]                         │
└──────────────────────────────────────────────┘
```

**Props:**
```typescript
interface TestPanelProps {
  open: boolean;
  onClose: () => void;
  expression: string;
  dependsOn: string[];  // Auto-detected field dependencies
}
```

**States to handle:**
- **Empty/no fields**: If `dependsOn` is empty, show a message "No dependencies to test. Add field references to your expression first."
- **Loading**: Show spinner/spinner overlay while the API call is in flight
- **Error**: Show error message if the API returns an error (e.g., parse error)
- **Success**: Show the result with formatted display
- **Empty result**: Handle null/undefined results gracefully

**Implementation specifics:**
- Use shadcn Dialog component for the modal (import from `@/components/ui/dialog`)
- Auto-generate input fields from `dependsOn` array
- Support different input types based on field names (number inputs for price/quantity/count, text inputs otherwise)
- Use `testExpression()` API to evaluate with the entered values
- Display results with appropriate formatting:
  - Numbers → show as number
  - Text → show as text
  - Dates → show formatted date
  - Boolean → show as "Yes"/"No"
- Show the original expression read-only at the top
